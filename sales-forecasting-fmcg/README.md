FMCG Sales Forecasting (ARIMA / SARIMA)
This project implements an end-to-end sales demand forecasting pipeline for the FMCG/Retail industry.
The objective is to forecast product demand to support inventory planning and stock optimization.
The project compares regression-based and classical time-series forecasting techniques using real retail sales data.

Techniques Used
Linear Regression (baseline with price and calendar features)
ARIMA (time-series forecasting using historical demand)
SARIMA / SARIMAX (seasonal ARIMA with external variables such as price and holidays)
Daily and Weekly aggregation for improved forecast interpretability

Dataset
This project uses the Walmart M5 Forecasting – Accuracy dataset, a widely used public FMCG retail dataset that includes:
Historical daily sales
Calendar information (holidays, events)
Weekly product pricing

Due to file size limitations and repository best practices, the raw dataset is not included in this repository.
