Credit Card Fraud Detection
- Built a fraud detection and alert system using the IEEE-CIS dataset
- Implemented memory-safe preprocessing and sparse Logistic Regression
- Tuned decision thresholds using precision–recall trade-offs
- Focused on realistic, production-style ML design
